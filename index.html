HOW I WORK

The loop I run my agents on

AI agents write code fast, but working code is not the same as trustworthy code. I wrap every agent in three steps, and none of them gets skipped.

SPECIFY RUN VERIFY
  1. 01

    SPECIFY

    Write the spec, the API contract and the agent rules before handing anything off, so the agent knows what it may do and what it must not touch.

    • AGENTS.md

ABOUT

About

I trained as a software engineer, then spent two years in marketing for a manufacturer selling into the US. Those years taught me what the people using an AI feature actually need: ops wants invoices entered faster, sales wants stock answers without asking anyone, a shop owner wants listings without typing them. In 2026 I went back to writing code, this time alongside AI agents. What I'm good at is not the prompting; it's the rules and the verification that make agent output trustworthy — every database write has a human approving it, and nothing reaches production without tests.
